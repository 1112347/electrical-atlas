# ⚡ 电气知识图鉴

一个无需服务器、无需 API Key 的移动端电气工程知识卡网页。内置五张初始卡片及十张自动解锁的后续卡片、B站/知乎延伸资料、学习与复习记录、私人收藏、AI 提问跳转和 JSON 备份。

## 1. 首次发布 GitHub Pages

1. 登录 [GitHub](https://github.com/)，新建仓库，推荐命名 `electrical-atlas`，选择 **Public**（GitHub Free 的 Pages 通常通过公开仓库发布）。
2. 将部署包里的 `index.html`、`site.webmanifest`、`.nojekyll` 和 `icons/` 文件夹**放在仓库根目录**。`README.md` 也可以一起上传。可以通过网页中的 **Add file → Upload files → Commit changes** 上传。
3. 进入仓库 **Settings → Pages**，在 **Build and deployment** 下将 **Source** 设为 **Deploy from a branch**，选择 `main` 分支和 `/(root)` 文件夹，保存。
4. GitHub 完成部署后，访问 `https://你的GitHub用户名.github.io/electrical-atlas/`。以 Pages 设置里显示的实际网址为准。
5. 在手机浏览器打开此网址；需要的话，通过浏览器菜单「添加到主屏幕」创建快捷入口。不同浏览器安装支持程度不同，离线使用并不保证。

> GitHub Pages 是公开网站，请不要将投标文件、真实工程项目资料、密码或其他保密信息上传至仓库。学习笔记目前只保存在打开网站的浏览器本地，不会自动同步至 GitHub。

## 2. 以后如何更新

只需把新版 `index.html`（或本次更新涉及的文件）上传到同一个仓库相同位置，并 **Commit changes**。GitHub Pages 会自动部署；刷新手机网页即可看到新版。无需更换站点网址。

- 网页代码变更和学习记录是两回事：学习记录使用浏览器 `localStorage`，**相同域名、相同浏览器**通常会保留。
- **从旧版本地 HTML 第一次迁移到 GitHub Pages 时，浏览器不会自动搬运数据。** 务必先在旧版点「导出全部卡片与学习记录」，在 GitHub Pages 网址中点「导入备份」。
- 更换设备/浏览器、清理网站数据或网址变化，也需用 JSON 手动迁移。建议每周导出一次备份并存到自己的私有云盘。
- 当前没有账户登录、云端自动同步或提醒推送。

## 3. AI 提问的工作方式

在首页「随手向 AI 提问」输入问题（留空则自动生成一个碎片学习主题），或在具体卡片点「带着这张卡问 AI」。网页会把卡片名称、已有知识要点、用户问题和讲解格式组织成一个提示词，访问：

`https://chatgpt.com/?q=<URL编码的提示词>`

在 ChatGPT 中检查是否已预填，然后自行发送。跳转能否自动传递内容取决于 ChatGPT 客户端，若失败，点原网页的「复制提问内容」手动粘贴。不调用付费 API，也不需要在网站输入 ChatGPT 密钥。不要在问 AI 时附带机密工程信息。

## 4. 文件结构

```
index.html          # 网站主页、卡片、复习、数据管理和 AI 跳转逻辑
site.webmanifest    # 适配「添加到主屏幕」的网页清单
icons/             # 网站图标（SVG、192px 和 512px PNG）
.nojekyll           # GitHub Pages 直接发布静态文件
README.md           # 部署与使用说明
```

## 6. v1.2 修复与迁移核对

- 每张卡的 AI 提示词带完整正文及自测题，页面显示完整提示词供手动复制。超长提示词打开 ChatGPT 后手动粘贴，避免网址过长。预填参数是便捷入口，无法保证所有客户端支持，也不会自动发送问题。私人笔记和资料收藏不加入提示词；自建卡的正文会加入。
- 保持原有 localStorage 键和备份 version 1，旧备份可继续导入。导入替换学习进度、个人卡、资料及评价；缺少资料字段的旧备份会将这些字段置空。导入前先导出当前数据。
- 备份保存所有卡片；新版中已删除的旧卡也能从备份找回。同 ID 的内置卡显示新版正文，旧快照仍保存在 archive 中。
- localStorage 按域名、协议和端口隔离，同一 github.io 域名下不同项目路径共用这些存储键；不要在同一账号下部署多份本应用保存独立数据。
- 复习间隔为 1、3、7、14、30、60、120 天，记住后推进一级，未记住回到 1 天；这是学习工具的简易安排。
- 更新前先导出 JSON；保留五张内置卡的标题/ID 及存储键，避免旧学习记录失联。

## 8. v1.3 自动补充课程

初始显示五个单元，内置十个后续单元。每个课程单元首次标为学过，自动解锁一个后续单元；复习、收藏、笔记或自建卡不触发重复解锁。旧记录自动补齐应解锁数量。新单元有 B站/知乎搜索入口、厂家参考链接、问 AI、自测和复习功能。

解锁状态通过卡片档案及学习记录持久保存，并包含在原 JSON 备份中，导入后自动恢复。旧版数字索引资料收藏迁移为卡片 ID，新增卡不会把资料归到错误卡片。

本批共十五个单元；耗尽后显示已全部解锁，后续需更新预置知识库。这里的自动更新是按学习进度解锁预置内容，不调用 AI API，也不会无限生成课程。
