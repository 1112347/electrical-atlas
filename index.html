网站如何更新？我的卡片会丢吗？
  1. 更新前点上方 「导出全部卡片与学习记录」，保存 JSON 备份。
  2. 如果是本地 HTML 文件：用新版 HTML 替换旧文件，再打开；若看不到历史记录，点「导入备份」恢复。
  3. 如果部署在 GitHub Pages：在仓库中更新 index.html 等网站文件，提交修改后等待自动发布，再刷新网页。
  4. 同一网址、同一浏览器通常能保留本地记录；第一次从本地 HTML 搬到 GitHub Pages 时，一定要从原网页导出 JSON，再到新网址导入。换设备、换浏览器或清除网站数据后，也需通过备份恢复。目前不支持自动跨设备同步。
